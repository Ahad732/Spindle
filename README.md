# Spindle

Spindle is a lwo-cost, custom e-reader made with the RP2350A. It consists of a 2.7 inch e-paper display, which is much better than a typical screen. It also consists of a 128Mbit flash, which is 16MiB, and 5 user buttons. The firmware for Spindle can be found [here](https://github.com/Keyaan-07/spindle-firmware/tree/main). The firmware is custom written in C. 

See the board on [KiCanvas](https://kicanvas.org/?repo=https%3A%2F%2Fgithub.com%2FAhad732%2FSpindle%2Ftree%2Fmain%2FHardware)  

We made this project as a fun way to learn to integrate various components and work together on different parts of the same project!
